**取代 [ADR 0005](0005-bilingual-docs-mirror-tree.md)**：镜像目录结构，以及「新文档必须在所有语言版本中都存在才算完成」的规则保持不变；变化的只是语言数量——从两种变为三种，本记录取代 ADR 0005 成为当前策略的权威说明。ADR 0005 仍然作为历史记录保留，说明镜像结构最初为何是这个样子。

# 三语文档——`docs/zh/` 加入 `docs/en/` + `docs/ru/`

我们新增了简体中文(`zh-Hans`)作为第三种文档语言，原因与 ADR 0005 中添加俄语的原因相同：不熟悉英语的读者也需要能读懂本仓库的文档。`docs/zh/` 完全遵循 ADR 0005 为 `docs/ru/` 建立的结构——`docs/` 目录下所有内容的完整镜像，而 `README.md`/`CONTEXT.md` 仍然以英语为权威版本留在仓库根目录，其中文译文位于 `docs/zh/README.md`/`docs/zh/CONTEXT.md`。每个文件顶部的语言切换栏现在按语言加入的先后顺序列出全部三种语言(`🇬🇧 English · 🇷🇺 Русский · 🇨🇳 中文`)，译文一侧切换栏下方的说明依旧标注来源文件，并指向管理该约定的 ADR——现在是 0006，而不是 0005。

我们在引入 `docs/zh/` 的同一次改动中，把所有已存在的文档一次性回填完毕，而不是让 `zh` 长期处于部分覆盖的状态：ADR 0005 的前提正是——只要有任何一侧被单独添加内容，镜像就不再可信；`zh` 长期只覆盖一部分，正是这条规则本要防止的那种漂移。

中文译文目前是机器翻译的初稿，尚未经过以中文为母语或精通中文者的校对：在有人对照英文原文校对之前，请把 `docs/zh/` 视为「功能上大致准确、但未经校对」。

我们没有为三套目录树的同步添加自动化检查(无脚本、无 CI 检查)——本仓库目前只有 9 篇文档，也没有可供挂载此类检查的自身 CI 流水线，因此同步校验脚本是为一个目前尚能凭人工记住的小问题构建的多余基础设施。如果文档数量增长到人工纪律不再可靠的程度，值得重新考虑。

结论：与 ADR 0005 相同的规则，范围更宽——现在每一篇新文档都必须同时加入 `docs/en/`、`docs/ru/`、`docs/zh/`，才算完成。
