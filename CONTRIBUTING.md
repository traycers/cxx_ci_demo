# Contributing

## Keeping the trilingual docs in sync

Documentation is maintained in English, Russian, and Chinese — canonical English under `docs/en/` (plus the root `README.md`/`CONTEXT.md`), mirrored at `docs/ru/` and `docs/zh/`. See [ADR 0006](docs/en/adr/0006-trilingual-docs-mirror-tree.md) for why.

When you change an English doc, update its `docs/ru/` and `docs/zh/` counterparts in the same change — a new doc isn't done until it exists on all three sides.
